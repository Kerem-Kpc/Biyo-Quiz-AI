# How to Get a Google AI API Key

Follow these steps to get a free API key to use with the Gemini API.

1.  **Go to Google AI Studio:**
    Open your web browser and navigate to [https://aistudio.google.com/](https://aistudio.google.com/).

2.  **Sign In:**
    If you are not already signed in, sign in with your Google account.

3.  **Get API Key:**
    Click on the "**Get API key**" button. You can usually find this in the left-hand menu or as a prominent button on the page.

4.  **Create API key in a new project:**
    You will be prompted to create a new Google Cloud project to associate your API key with. Follow the on-screen instructions to create the project.

5.  **Copy Your Key:**
    Once the key is generated, a string of characters will appear. Use the copy button to copy the key to your clipboard.

6.  **Paste into the `.env` file:**
    - Open the `.env` file in your project.
    - Paste the copied key directly after `GEMINI_API_KEY=`.
    - Save the file.
