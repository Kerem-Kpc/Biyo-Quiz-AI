# **App Name**: BioQuiz AI

## Core Features:

- PDF Upload: Allow users to upload biology PDFs to the site.
- Quiz Generation: Automatically generate multiple-choice questions from the content of the uploaded PDF using a tool.
- Quiz Display: Display the generated quiz to the user in a clear and interactive format.
- Answer Submission: Enable users to submit their answers to the quiz.
- Automatic Grading: Automatically grade the quiz and provide immediate feedback to the user.
- Explanation Tool: Provide AI-powered explanations for correct and incorrect answers.

## Style Guidelines:

- Primary color: Soft Green (#A7D1AB) for a natural and organic feel, reflecting biology.
- Background color: Light Beige (#F5F5DC), a desaturated version of the primary color, for comfortable readability.
- Accent color: Muted Blue (#77B5FE) to highlight important elements and interactive components.
- Body and headline font: 'Inter', sans-serif.
- Use biology-related icons that are simple and easy to understand.
- Clean, intuitive layout for easy navigation and comfortable reading.
- Subtle animations to provide feedback on quiz submissions and correct/incorrect answers.
